**PLAY NO LIMIT by SirenaGoloviy**

**TITAN FIX8 · 1.0.6 · Kraken Mount 0.3.0**

Интеграция изменений Kraken Mount 0.3.0 поверх FIX7 с сохранением настроек, обновлятора, бэкпортов и выбора PlayGo по играм.

## Что изменилось

- **Сохранения:** обычный `fakelib` больше не подменяет системный модуль через `libSceSaveData.native.sprx`. Явные библиотеки бэкпорта и `fakelib2` сохраняются.
- **PKG:** обязательный AMPR остаётся включён даже при выключенном `inject_ampr`. Более новый AMPR игры не заменяется старым. Приоритет установленных внутренних PKG и запуск внешних архивов без переноса сохранены.
- **PlayGo:** та же библиотека Stub 0.6, автоматическое добавление при обнаружении импорта в `eboot.bin`, обновление известных Stub 0.4/0.5 и сохранение неизвестной собственной библиотеки. Галочки выбора игр, исключения и ручной файл в AMPR сохраняют действие.
- **Копирование:** недавно изменённые источники ожидают стабилизации, по умолчанию 10 секунд. Задержка настраивается.
- **Автоудаление плиток:** включено по умолчанию, задержка 300 секунд. Только при подтверждённом отсутствии исходника снимается регистрация собственной плитки TITAN; кэш остаётся, возвращённый источник регистрируется снова. Установленные системные PKG, YouTube и чужие плитки ShadowMount защищены. Ошибка чтения сама по себе не запускает удаление.
- **USB:** кнопка извлечения с проверками в «Хранилище». Извлечение блокируется при игре, установке, операциях с бэкпортами и зарегистрированных папках/образах ShadowMount. При отказе или отсутствии подтверждения оставьте диск подключённым.
- Названия игр на языке консоли и звук плитки при наличии `snd0.at9`.

**DLC-эмулятор 0.3 из upstream не включён:** в документации его релиза отмечены неисправленные ошибки RPC. Существующие библиотеки игр обрабатываются по настройкам TITAN. Готовые игровые бэкпорты в сборку не добавлены; собственный файл каталога в репозитории пока недоступен.

## Как обновить

1. Закройте игры и полностью перезагрузите PS5.
2. Загрузите **`TITAN-SirenaGoloviy-fix8.elf`** через Payload Manager либо выберите FIX8 в обновляторе установленного FIX7. После установки обновлятором выполните полную перезагрузку и запустите сохранённый ELF.
3. Замените старую копию в автозагрузке/источнике Payload Manager. Отдельный автозапуск Kraken или ShadowMount для объединённого TITAN не требуется.
4. Откройте **`http://IP_ПС5:8097`**. Первый запуск обновит слои библиотек игр; дождитесь **Ready** перед запуском.

В **«Настройки → Библиотека и хранилище»** можно выключить автоудаление или изменить задержки. При отключении USB его плитки могут скрыться через пять минут — это ожидаемое поведение при включённой функции. Исходные архивы и кэш она не удаляет.

С FIX6 переходите вручную: старый обновлятор закреплён на прежнем адресе репозитория. [Полная инструкция](https://github.com/grimmtroll2285-dot/TITAN#readme).

## Файлы и проверка

- **Надгрузка:** `TITAN-SirenaGoloviy-fix8.elf`.
- **Полные соответствующие исходники:** `TITAN-SirenaGoloviy-fix8-source.zip`. Автоматические архивы GitHub Source code их не заменяют.
- **Контрольные суммы и результаты:** `SHA256SUMS.txt`, `validation.json`.
- **Границы интеграции:** `KRAKEN_0_3_0_UPGRADE.md`.

Прошли 123 теста на ПК, проверка типов PS5, синтаксиса интерфейса и обеих стадий ELF. Проверено сохранение новых настроек на синтетическом предпросмотре.

**FIX8 не проверен на реальной PS5.** Проверки ПК не подтверждают запуск конкретных игр, сохранения, автоудаление, извлечение USB или обновление после перезагрузки. Основная целевая конфигурация — PS5 13.60. Не запускайте игру во время подготовки кэша; PlayGo не заменяет необходимый бэкпорт и не гарантирует совместимость всех игр.
