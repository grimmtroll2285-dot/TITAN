# История изменений TITAN

## FIX12 — 1.0.10 · 2026-11-24 · stable

- **Kraken Mount 0.3.2 и официальный AMPR 0.5.1.** Обновлены нативный движок и модуль чтения упакованных игр.
- **Закрытие и переход между ELF игры:** собственные монтирования в песочнице снимаются сразу после выхода, библиотечный overlay кратко сохраняется для перехода к следующему ELF той же игры. Занятые и чужие монтирования принудительно не снимаются.
- **Исправления AMPR от upstream:** сохранения в PKG, зависание Hades при закрытии, чтение каталогов в DIRT 5, MARVEL Cosmic Invasion и Scott Pilgrim EX. Работа конкретных игр в TITAN требует проверки на PS5; исправление сохранений Wolverine ещё не подтверждено автору отчёта.
- **Библиотека:** поиск по названию, Title ID и пути; фильтр по накопителю; кнопка «Играть» для готовых нативных игр.
- **Диагностика:** сохранение последнего обнаруженного сбоя и текстовый отчёт из карточки игры. Полный дамп ядра не скачивается автоматически.
- **Настройки:** исключение файлов и папок из нативного сканирования; отключение библиотечного overlay отдельно для игры в папке. Для PKG обязательный AMPR сохраняется.
- **Playden:** подмножество API v1 нативной библиотеки на порту 8097: список, сканирование, исключения, снятие собственной регистрации без удаления исходника и переключение overlay.
- **FW 12+:** восстановление плитки TITAN через пакетную регистрацию и повторное открытие веб-порта после выхода из режима покоя.

Сохранены обновлятор TITAN с выбором версии и откатом, PlayGo 0.6 с выбором игр, бэкпорты, автоудаление только собственных пропавших плиток, защита YouTube и сторонних монтирований. Внешние архивы PKG сканируются только в `<диск>/homebrew/` и её подпапках. Файлы установленных системных PKG остаются на своих местах.

**FIX12 — стабильный выпуск (1.0.10), не pre-release.** Статус релиза не означает подтверждённую совместимость всех игр. Аппаратные испытания FIX12 и замеры производительности на PS5 не выполнялись. # FIX8 · 1.0.6

**PLAY NO LIMIT by SirenaGoloviy**

**TITAN FIX8 · 1.0.6 · Kraken Mount 0.3.0**

Интеграция изменений Kraken Mount 0.3.0 поверх FIX7 с сохранением настроек, обновлятора, бэкпортов и выбора PlayGo по играм.

## Что изменилось

- **Сохранения:** обычный `fakelib` больше не подменяет системный модуль через `libSceSaveData.native.sprx`. Явные библиотеки бэкпорта и `fakelib2` сохраняются.
- **PKG:** обязательный AMPR остаётся включён даже при выключенном `inject_ampr`. Более новый AMPR игры не заменяется старым. Приоритет установленных внутренних PKG и запуск внешних архивов без переноса сохранены.
- **PlayGo:** та же библиотека Stub 0.6, автоматическое добавление при обнаружении импорта в `eboot.bin`, обновление известных Stub 0.4/0.5 и сохранение неизвестной собственной библиотеки. Галочки выбора игр, исключения и ручной файл в AMPR сохраняют действие.
- **Копирование:** недавно изменённые источники ожидают стабилизации, по умолчанию 10 секунд. Задержка настраивается.
- **Автоудаление плиток:** включено по умолчанию, задержка 300 секунд. Только при подтверждённом отсутствии исходника снимается регистрация собственной плитки TITAN; кэш остаётся, возвращённый источник регистрируется снова. Установленные системные PKG, YouTube и чужие плитки ShadowMount защищены. Ошибка чтения сама по себе не запускает удаление.
- **USB:** кнопка извлечения с проверками в «Хранилище». Извлечение блокируется при игре, установке, операциях с бэкпортами и зарегистрированных папках/образах ShadowMount. При отказе или отсутствии подтверждения оставьте диск подключённым.
- Названия игр на языке консоли и звук плитки при наличии `snd0.at9`.

**DLC-эмулятор 0.3 из upstream не включён:** в документации его релиза отмечены неисправленные ошибки RPC. Существующие библиотеки игр обрабатываются по настройкам TITAN. Готовые игровые бэкпорты в сборку не добавлены; собственный файл каталога в репозитории пока недоступен.

## Как обновить

1. Закройте игры и полностью перезагрузите PS5.
2. Загрузите **`TITAN-SirenaGoloviy-fix8.elf`** через Payload Manager либо выберите FIX8 в обновляторе установленного FIX7. После установки обновлятором выполните полную перезагрузку и запустите сохранённый ELF.
3. Замените старую копию в автозагрузке/источнике Payload Manager. Отдельный автозапуск Kraken или ShadowMount для объединённого TITAN не требуется.
4. Откройте **`http://IP_ПС5:8097`**. Первый запуск обновит слои библиотек игр; дождитесь **Ready** перед запуском.

В **«Настройки → Библиотека и хранилище»** можно выключить автоудаление или изменить задержки. При отключении USB его плитки могут скрыться через пять минут — это ожидаемое поведение при включённой функции. Исходные архивы и кэш она не удаляет.

С FIX6 переходите вручную: старый обновлятор закреплён на прежнем адресе репозитория. [Полная инструкция](https://github.com/grimmtroll2285-dot/TITAN#readme).

# TITAN · FIX7 · 1.0.5 · SirenaGoloviy

PLAY NO LIMIT by SirenaGoloviy

TITAN CORE переименован в TITAN. В этой версии собраны вкладка бэкпортов и выбор PlayGo по списку игр поверх FIX6.

## Что изменилось

- Название интерфейса, плитки и уведомлений: TITAN. Новый адрес репозитория: https://github.com/grimmtroll2285-dot/TITAN. Внутренние пути /data/titan-core, кэши, настройки и идентификаторы движков сохранены для совместимости.
- Настройки → PlayGo: отдельный видимый блок, поиск и галочки напротив игр. Включённая галочка разрешает PlayGo от TITAN; выключенная оставляет библиотеку игры. Вводить Title ID больше не нужно. Существующие исключения, включая игры на отключённых дисках, сохраняются. Выбор общий для одного Title ID. Для новых игр PlayGo разрешён по умолчанию; общий переключатель PlayGo и inject_ampr сохраняют приоритет.
- Вкладка «Бэкпорты» показывает библиотеку и подбирает патчи для родного движка TITAN по Title ID, точной версии, диапазону прошивки, формату и модели PS5/Slim или Pro. Поддерживаются PS5 PKG и папки; установка патчей для образов ShadowMount пока недоступна.
- Скачивание патча запускает пользователь. Проверяются размер и SHA-256 каждого файла, безопасные пути и совпадение идентификатора/версии в param.json. Оригинальные PKG, игры и сохранения не перезаписываются.
- Скачанные файлы хранятся отдельно. Применение и возврат предыдущего выбора требуют полной перезагрузки PS5; простой перезапуск TITAN недостаточен. Есть отключение и отмена ожидающего изменения. Повреждённый новый комплект не заменяет предыдущий выбор.
- Собственный каталог TITAN подключён по умолчанию: https://raw.githubusercontent.com/grimmtroll2285-dot/TITAN/main/backports/catalog.json. Автоматическая проверка через 35 секунд после старта и каждые 30 минут; установки без нажатия кнопки нет. Можно добавить свои каталоги GitHub или импортировать JSON. В исходниках есть упаковщик папки/ZIP в каталог с SHA-256.
- Добавлены справочные ссылки на BackPork, PS5 Backport Toolkit и PS5 Game Updater. Это инструменты и информация, а не совместимые каталоги автоматической установки. На 18.11.2026 публичный verified-seed.json Game Updater пуст; BackPork публикует BPS-патчи, требующие исходных библиотек.

**Каталог TITAN пока пуст: готовых проверенных игровых бэкпортов в FIX7 нет.** Подбор и загрузка появятся для игры после добавления подходящего комплекта в подключённый каталог. Совместимость каждого бэкпорта требует отдельной проверки. Вкладка не генерирует патчи и не скачивает целые игры.

## Переход с FIX6 после переименования репозитория

1. Загрузите TITAN-SirenaGoloviy-fix7.elf из Assets вручную. Старый обновлятор FIX6 жёстко проверяет адреса прежнего репозитория и может перестать видеть выпуски после переименования. Автоматический переход с FIX6 не обещается.
2. Закройте игры, полностью перезагрузите PS5 и запустите новый ELF через Payload Manager. Обновите также старый файл в автозагрузке/локальном источнике Payload Manager, иначе он может снова сохранить старую сборку.
3. Откройте http://IP_ПС5:8097 и дождитесь готовности. Для объединённой сборки отдельный автозапуск Kraken/ShadowMount не нужен. Существующий jailbreak/elfldr оставьте.
4. Для PlayGo: «Настройки → PlayGo», выберите игры и нажмите «Сохранить». Закройте игры и дождитесь готовности кэша перед запуском.
5. У обновлятора FIX7 новый адрес TITAN. Доступны стабильные/pre-release и выбор версии для обновления/даунгрейда. При откате на FIX6 старый адрес обновлятора возвращается: для перехода обратно на FIX7 может снова понадобиться ручная загрузка.

Каталог Payload Manager с аватаркой: https://github.com/grimmtroll2285-dot/TITAN/releases/download/fix7/payloads.json

Сторонние патчи проверяйте на точное соответствие своей версии/прошивке/модели.

Сохранены компоненты FIX6: Kraken Mount 0.2.1, AMPR 0.4.1, оригинальный drakmor PlayGo Stub 0.6, ShadowMountPlus 1.7beta12-titan-isolated4, kstuff-lite 1.11. Отдельные экспериментальные изменения расследования PKG/fakelib2 сюда не включены. Native PS4, retail/encrypted PKG, AES-XTS и отдельные LIH-патчи не добавлены. Игра с внешнего диска требует подключённого оригинала и внутреннего кэша.

Полные соответствующие исходники: TITAN-SirenaGoloviy-fix7-source.zip в Assets. Автоматический GitHub Source code содержит страницу распространения, а не полный исходный код ELF. Авторство и лицензии upstream сохранены.

# Fix3 — обычная версия

## Регистрация и YouTube

В объединённой сборке удалён безусловный общий вызов регистрации всех приложений
как запасной путь. Вместо него используется адресный API встроенной службы,
который вызывает существующий механизм регистрации одного Title ID.
На FW12+ исходный мост ShadowMount использует перехваченный AppInstallAll как
транспорт к внутренней адресной функции — это не прежний безусловный общий обход.
Если мост недоступен, операция возвращает ошибку вместо массовой регистрации.

Три региональных Y2JB Title ID исключены из подготовки, регистрации и наложений:
`PPSA01650`, `PPSA01651`, `PPSA01652`.
Изменение существующей иконки обратно и восстановление удалённых файлов не добавлены.

## Владение монтированиями

Служба подтверждает нативное владение до регистрации и базового монтирования.
Подтверждение сверяется с запрошенным Title ID. ShadowMount пропускает fakelib,
PKG-backport и свою подготовку монтирования для подтверждённых нативных игр.
Существующий чужой `mount.lnk` блокирует перехват: ссылки не удаляются автоматически.
Владение действует до перезапуска службы; настройка для обычных raw PKG не
сохраняется как постоянное пользовательское переопределение.

## Закрытие

После завершения процесса TITAN очищает свои слои без принудительного
размонтирования по тайм-ауту. Занятые слои остаются на учёте, повторные попытки
продолжаются, нативное сканирование остаётся приостановленным.
Если событие NOTE_EXIT не обработано, периодическая проверка исчезнувшего
процесса ставит обычную очистку в очередь. Работающая игра не убивается.
Эти изменения не гарантируют устранение любого зависания игры или ядра.

## Сохранено

Отключены оба ранее выявленных фоновых пути AppUnInstall во встроенном
ShadowMount; явное ручное удаление через API сохранено. Сохранены адресная
проверка регистрации по действующей строке SQLite, повтор ошибок готового кэша
и подпись `PLAY NO LIMIT by SirenaGoloviy`.

## Не включено

Отдельная USB-поправка с прямым поиском обычных внешних PKG и пять новых
улучшений интерфейса/диагностики в этот релиз не входят.
