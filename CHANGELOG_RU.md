# Fix3 — обычная версия

## Регистрация и YouTube

В объединённой сборке удалён безусловный общий вызов регистрации всех приложений
как запасной путь. Вместо него используется адресный API встроенной службы,
который вызывает существующий механизм регистрации одного Title ID.
На FW12+ исходный мост ShadowMount использует перехваченный AppInstallAll как
транспорт к внутренней адресной функции — это не прежний безусловный общий обход.
Если мост недоступен, операция возвращает ошибку вместо массовой регистрации.

Три региональных Y2JB Title ID исключены из подготовки, регистрации и наложений:
`PPSA01650`, `PPSA01651`, `PPSA01652`.
Изменение существующей иконки обратно и восстановление удалённых файлов не добавлены.

## Владение монтированиями

Служба подтверждает нативное владение до регистрации и базового монтирования.
Подтверждение сверяется с запрошенным Title ID. ShadowMount пропускает fakelib,
PKG-backport и свою подготовку монтирования для подтверждённых нативных игр.
Существующий чужой `mount.lnk` блокирует перехват: ссылки не удаляются автоматически.
Владение действует до перезапуска службы; настройка для обычных raw PKG не
сохраняется как постоянное пользовательское переопределение.

## Закрытие

После завершения процесса TITAN очищает свои слои без принудительного
размонтирования по тайм-ауту. Занятые слои остаются на учёте, повторные попытки
продолжаются, нативное сканирование остаётся приостановленным.
Если событие NOTE_EXIT не обработано, периодическая проверка исчезнувшего
процесса ставит обычную очистку в очередь. Работающая игра не убивается.
Эти изменения не гарантируют устранение любого зависания игры или ядра.

## Сохранено

Отключены оба ранее выявленных фоновых пути AppUnInstall во встроенном
ShadowMount; явное ручное удаление через API сохранено. Сохранены адресная
проверка регистрации по действующей строке SQLite, повтор ошибок готового кэша
и подпись `PLAY NO LIMIT by SirenaGoloviy`.

## Не включено

Отдельная USB-поправка с прямым поиском обычных внешних PKG и пять новых
улучшений интерфейса/диагностики в этот релиз не входят.
