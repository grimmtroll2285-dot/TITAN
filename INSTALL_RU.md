# Установка и проверка обычного Fix3

Файл: [TITAN-CORE-SirenaGoloviy-fix3.elf](https://github.com/grimmtroll2285-dot/TITAN-CORE-SirenaGoloviy/releases/download/fix3-standard/TITAN-CORE-SirenaGoloviy-fix3.elf). Не выбирайте автоматически созданные GitHub
`Source code (zip/tar.gz)` вместо ELF. Полные исходники сборки — отдельный Asset
`TITAN-CORE-SirenaGoloviy-fix3-source.zip`.

## Перед запуском

Закройте игру и полностью перезагрузите PS5. Отключите отдельный автозапуск
Kraken и ShadowMount для этого набора, чтобы не запускать две версии службы.
Jailbreak/elfldr и Payload Manager используются привычным способом.
Запустите новый ELF вместо прежнего TITAN. Настройки, исходные PKG и сохранения
для установки этого выпуска удалять не требуется.

## После запуска

Откройте `http://IP_ПС5:8097`. Проверьте Diagnostics и версию встроенной службы
`1.7beta10-titan-isolated3`. При сообщении о старой службе выполните полную
перезагрузку и исключите отдельный автозапуск старого ShadowMount.

Проверьте иконку YouTube до и после подготовки игры, затем запуск и закрытие
одной игры. Уже изменённая карточка не восстанавливается этой сборкой напрямую.
Если закрытие зависло, до перезагрузки сохраните журнал TITAN и журнал ядра
из Diagnostics. Укажите игру, Title ID и расположение исходного пакета.

## Внешний диск виден, но обычный PKG не появляется

В **обычном Fix3** сохраняется фильтр внешних архивов: обычные внешние `.pkg`
без отметки установщика TITAN не становятся автоматическими нативными источниками.
Отдельная USB-поправка не опубликована по решению владельца сборки.
Это ограничение версии, а не свидетельство неисправности диска.

