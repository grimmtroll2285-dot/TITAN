# Установка TITAN FIX7 1.0.5

1. Скачайте [TITAN-SirenaGoloviy-fix7.elf](https://github.com/grimmtroll2285-dot/TITAN/releases/download/fix7/TITAN-SirenaGoloviy-fix7.elf).
2. Закройте игры, полностью перезагрузите PS5 и запустите ELF через Payload Manager.
3. Обновите старый ELF в автозагрузке и локальных источниках Payload Manager. Для объединённой сборки отдельные Kraken/ShadowMount не запускайте; jailbreak/elfldr сохраните.
4. Откройте http://IP_ПС5:8097 и дождитесь Ready. Не запускайте игру во время пересборки кэша.
5. Настройки → PlayGo: выберите игры галочками, нажмите «Сохранить».
6. Каталог бэкпортов уже подключён, но пока пуст. Для установки нужны проверенные комплекты точной версии игры/прошивки/модели; образы ShadowMount этой вкладкой не поддерживаются. Применение бэкпорта и откат — после полной перезагрузки.

После переименования репозитория обновлятор FIX6 может не видеть выпуски: первый переход на FIX7 выполните вручную. При даунгрейде на FIX6 возвращается его старый обновлятор.

Полная инструкция и пределы: [README](README.md), [бэкпорты](BACKPORTS.md), [PlayGo](PLAYGO_INTEGRATION.md). Обновлятор: [описание](CONSOLE-UPDATER.md).
